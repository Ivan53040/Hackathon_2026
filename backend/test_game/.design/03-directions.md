## A · 星圖　Starchart

**核心一句**：場地不是被打光的石頭，是一張發光的星圖——建築只有線，法師是圖上的星，牆是把星遮掉的暗雲。

**個性**：一個人在天文台裡把星圖投在牆上，安靜地推演。它不解釋自己，假設你看得懂。

| 欄位 | 內容 |
|---|---|
| **視覺語言** | 建築只有線沒有面，線自體發光。牆是唯一實心體，靠遮住背後的線被看見 |
| **Q02 第二層編碼** | 我方**填實圓**，敵方**空心環**；亮度差 2.94 倍 |
| **Q03 對手消失** | 星**熄滅成虛線輪廓**，位置還在；星座線同時斷開 |
| **Q04 數值牌** | 頭頂上方的格子條，不用文字。單層之後畫面上半全空，可以放很大 |
| **動態語言** | 整張星圖極慢飄移（20s 週期，4px）。**不動的是**：法師、牆、數值 |
| **使用者體驗** | 玩家讀「線通不通」來判斷打不打得到，跟規則同構 |
| **業務影響** | 買到最高的美術上限與團隊熟悉度；花掉的是在亮環境下的容錯 |
| **風險** | **細線是命門**——線寬 < 2px 在投影機上會消失。整體偏抽象，可能被讀成資料視覺化 |
| **最適場合** | 會場**能關燈**時，這個方向上限最高 |

**Anti-generic：NO**
1. 星座線的**斷開／接通**直接就是遊戲的視線規則
2. 牆是畫面上**唯一的實心體**，因為它是唯一會擋住東西的規則物件
3. 「星熄滅」用的是天文學自己的語彙（星等、遮掩）

**量測**：C1 `3.99:1` ✅　C2 `1.96:1` ✅　C3 `2.94×` ✅

## B · 石版　Codex

**核心一句**：整場對決是一塊被雕刻的石板——法師是刻進去的浮雕，牆是壓上去的石塊，符文是燒灼進石頭的金線。

**個性**：一塊在博物館玻璃櫃裡的石碑，上面記著一場很久以前的決鬥。它不發光，但你會湊近看。

| 欄位 | 內容 |
|---|---|
| **視覺語言** | **反轉底色。** 投影機做不出黑，只能做「比較少的光」——把亮度預算花在亮底上，深刻痕自然得到 8:1 |
| **Q02 第二層編碼** | 我方**金線描邊**，敵方**靛線**；人物本體同一種刻痕黑。亮度差 2.85 倍 |
| **Q03 對手消失** | 石塊**物理上蓋住**浮雕，後面是空石面加一道虛線影子。**最不可能被誤讀成掉線** |
| **Q04 數值牌** | 刻在角色旁邊的**計數短線**（正字記號邏輯），不是懸浮 UI。用掉的那格變淺＝被磨掉 |
| **動態語言** | 幾乎全靜，只有撞擊與崩塌會動，而且動得**重**（0.35s，強 ease-out，一次微震）。**不動的是**：底、光、鏡頭 |
| **使用者體驗** | 玩家讀「有沒有東西壓在前面」，是純物理判斷，零學習成本 |
| **業務影響** | 買到投影機上幾乎不可能失敗的對比與差異化；**花掉的是整個發光魔法感** |
| **風險** | **放棄發光。** Bloom 在亮底上無作用，「深夜魔法」氛圍全沒了。團隊可能覺得像博物館不像魔法 |
| **最適場合** | 會場**不關燈**、投影機老舊，或你要一個沒人做過的魔法遊戲外觀 |

**Anti-generic：NO**
1. 血量是**刻上去的計數線，用掉就被磨掉**——因為「血量不回復」正是規則
2. 牆是**壓上去的石塊**，「它擋住你自己」在物理上自明，不需要教學
3. 符文是**燒灼進石頭的痕跡**，跟「用筆畫」是同一個動作

**量測**：C1 `8.02:1` ✅✅　C2 `2.22:1` ✅　C3 `2.85×` ✅

## C · 皮影　Theatre

**核心一句**：這是一齣背光的皮影戲——角色永遠是純黑剪影，身分由他背後那道光的顏色決定，牆是切進光裡的黑塊。

**個性**：一塊繃緊的布，後面有兩盞打對台的燈。你看不到演員，只看得到他做了什麼。

| 欄位 | 內容 |
|---|---|
| **視覺語言** | 角色**永遠純黑**。黑形對亮底是投影機上能達到的最高對比，且完全不依賴顏色 |
| **Q02 第二層編碼** | **身分不在人身上，在幕上。** 左半幕暖橘、右半幕冷青，亮度差 3.41 倍 |
| **Q03 對手消失** | 剪影**併入黑塊變成同一團黑**。你看得到那團黑，所以知道他在裡面——**躲藏＝合體** |
| **Q04 數值牌** | **不在頭頂，燒在幕布上緣。** 因為身分已由幕承擔，數值跟著幕走——**永遠不會被擋住**，可以放超大 |
| **動態語言** | 光會呼吸（幕亮度 ±4%，6s 週期），法陣把幕烤亮。**不動的是**：剪影輪廓與地面線 |
| **使用者體驗** | 玩家讀「我背後是什麼顏色」來確認自己是誰，走位時身分感最強 |
| **業務影響** | 買到遠距離最快的可讀性與表演感；花掉的是玩家對自己動作的細節回饋 |
| **風險** | **冷側 3.34:1 vs 暖側 9.11:1，兩邊不對等**，青光半場的玩家比較難讀。純黑剪影**看不出角色在畫什麼符文**，施法資訊全靠法陣與拖尾承擔 |
| **最適場合** | 當「台上 90 秒」的權重遠高於「judge 自己玩」時 |

**Anti-generic：NO**
1. **身分由背景光承擔**，因為玩家會在自己半場來回走位——走位本身就是這個遊戲
2. **躲藏＝剪影併入黑塊**，把「看不到對手」變成形狀事件而非 UI 狀態
3. 皮影戲本來就是**用手在光前面做出東西**，跟在鏡頭前用筆畫符文是同一件事

**量測**：C1 `3.34:1` ✅　C2 `2.73:1` ✅　C3 `3.41×` ✅

## 五軸比較

若任兩欄在五軸中有四軸相同，那就不是三個方向，是一個方向配三個滑桿。**這三欄五軸全不同。**

| 軸 | A 星圖 | B 石版 | C 皮影 |
|---|---|---|---|
| **密度** | 稀疏 · 只有線 | 中等 · 有實體量感 | 極稀疏 · 大色面 |
| **動態** | 低 · 背景緩慢飄移 | 極低 · 只有撞擊但很重 | 高 · 光持續呼吸 |
| **飽和** | 近單色 · 藍為主 | 近單色 · 石灰調 | 高飽和 · 兩道對立色光 |
| **溫度** | 冷 | 暖（灰暖石） | 左右各半，暖冷對立 |
| **版面邏輯** | 嚴格對稱格線 | 格線但邊界不齊 | 刻意破格 · 左右不對稱 |
| **底色極性** | **暗底** | **亮底** | **亮底 + 黑形** |

## Stage 4 要決定什麼

挑一個，並且說出**放棄了什麼**。真正的取捨：

| 選擇 | 買到 | 放棄 |
|---|---|---|
| **A 星圖** | 最高美術上限、團隊最熟悉、最接近原本方向 | 賭會場能關燈。賭輸就整場看不見 |
| **B 石版** | 投影機上幾乎不可能失敗（8:1）、最強差異化 | 發光與「深夜魔法」氛圍，等於推翻 v2/v3 的美術方向 |
| **C 皮影** | 遠距離最好讀、最像一場表演 | 玩家看不見自己在畫什麼；冷暖兩側不對等 |

**把 [`03-directions.html`](./03-directions.html) 在會場的投影機上打開，四個模擬全開，站到十公尺外。**
三個方向會自己淘汰兩個，你不需要在螢幕前猜。
