三個方向，一個投影機會裁掉兩個

這不是 mockup，是量測台。三個方向用同一個場景畫出來：我走出掩體開火，對手躲在他的牆後面消失了。 上面四個開關模擬 demo 當天真正會發生的事——投影機洗掉對比、色覺異常、十公尺的距離、bloom 過曝。 每個方向下面的數字是從實際色票即時算出來的 WCAG 相對亮度，不是我寫上去的。

Question 01
掩體的三個時刻怎麼演？躲起來 / 走出來 / 牆吃下攻擊
Question 02
敵我識別除了色相之外，第二層編碼用什麼？
Question 03
「對手消失了」怎麼看起來像規則，不像掉線？
Question 04
頭頂 HP／MP 放哪、多大，才不會被牆擋住？
必須通過的三個閘門（來自 .design/00-brief.md）： C1 場地 vs 天空 ≥ 3:1　·　C2 受光面 vs 場地 ≥ 1.6:1　·　 C3 我方色 vs 敵方色的相對亮度差 ≥ 2 倍　·　 C4 敵我區分不得只靠色相（開「灰階」自己看）

星圖

Starchart

場地不是被打光的石頭，是一張發光的星圖——建築只有線，法師是圖上的星，牆是把星遮掉的暗雲。

同一個場景 · 我方（金）已走出掩體施法 · 敵方（青）被牆遮住，星熄了
躲起來星熄滅，連向它的星座線斷開
走出來星重新亮起，星座線接通＝可以互相打到
牆吃下攻擊暗雲炸開成一撮星塵，星圖的洞被補回來
Visual language
建築只有線，沒有面。線是自體發光的，所以不必依賴表面明暗——這正是繞過 C1 的方式。牆是唯一的實心體，它靠遮住背後的線被看見。
第二層編碼（Q02）
我方填實圓，敵方空心環。加上亮度差 2.9 倍，灰階下仍然分得開。
對手消失（Q03）
星熄滅成虛線輪廓，位置還在——所以是「他躲起來了」不是「他不見了」。星座線同時斷開。
數值牌（Q04）
頭頂上方的格子條，不用文字。單層之後畫面上半部全空，可以放很大。
Motion
整張星圖極慢地飄（週期 20s，位移 4px），像真的天球。不動的是：法師、牆、數值。動的只有背景與法陣。
Best case
若會場能關燈，這個方向的完成度上限最高，而且最接近原本的「深夜天文台」美術方向。
色票Hex相對亮度對天空閘門
Anti-generic：NO — 不會變成別人的東西
  1. 星座線的斷開／接通直接就是遊戲的視線規則，不是裝飾
  2. 牆是畫面上唯一的實心體，因為它是唯一會擋住東西的規則物件
  3. 「星熄滅」＝角色被遮蔽，用的是天文學自己的語彙（星等、遮掩）
Risk

線稿在投影機上比色塊更容易被洗掉——細線是這個方向的命門，線寬低於 2px 就會消失。 而且整體偏抽象，judge 可能第一眼讀成「資料視覺化」而不是「遊戲」。

石版

Codex

整場對決是一塊被雕刻的石板：法師是刻進去的浮雕，牆是壓上去的石塊，符文是燒灼進石頭的金線。

石板不需要打光 · 深刻痕對淺石面 8.0:1 · 這是投影機上最不會失敗的組合
躲起來石塊物理上壓在浮雕前面，後面是空的石面
走出來浮雕從石塊側邊浮出，邊緣有一道鑿痕
牆吃下攻擊石塊崩成碎塊掉在地上，金線在原地留一道焦痕
Visual language
反轉底色。投影機做不出黑，只能做「比較少的光」——所以把亮度預算花在亮底上，深刻痕自然得到 8:1。這是三個方向裡唯一不跟投影機對抗的。
第二層編碼（Q02）
我方金線描邊，敵方藍靛線；人物本體都是同一種刻痕黑。識別靠線的顏色 + 亮度差 2.85 倍。
對手消失（Q03）
石塊物理上蓋住浮雕，後面露出的是空的石面加一道虛線影子。最不可能被誤讀成掉線的一個。
數值牌（Q04）
刻在角色旁邊的計數短線（正字記號的邏輯），不是懸浮 UI。用掉的那一格變成淺色＝被磨掉。
Motion
幾乎全靜，只有撞擊與崩塌會動，而且動得重（0.35s，強 ease-out，帶一次微震）。不動的是：底、光、鏡頭。
Best case
會場不關燈、投影機老舊、或你想要一個沒有人做過的魔法遊戲外觀時，這是唯一安全的選擇。
色票Hex相對亮度對石版底閘門
Anti-generic：NO — 沒有人這樣做魔法對戰
  1. 血量是刻上去的計數線，用掉就被磨掉——因為「血量不會回復」正是規則
  2. 牆是壓上去的石塊，所以「它擋住你自己」在物理上是自明的，不需要教學
  3. 符文是燒灼進石頭的痕跡，跟「筆」這個實體輸入裝置是同一個動作
Risk

放棄了發光。Bloom 在亮底上毫無作用，「深夜魔法」的氛圍整個沒有了， 而那是原本 v2/v3 美術方向的全部。團隊可能會覺得「這看起來不像魔法，像博物館」。 這是三個裡面最需要你有膽量的一個。

皮影

Theatre

這是一齣背光的皮影戲：角色永遠是純黑剪影，身分由他背後那道光的顏色決定，牆是切進光裡的黑塊。

剪影對幕光 9.1:1（暖側）／3.3:1（冷側）· 身分在幕上，不在人身上 · 數值永遠不會被遮住
躲起來剪影併入黑塊，變成同一團黑——躲藏在視覺上是「合體」
走出來剪影從黑塊剝離，中間裂開一道亮縫
牆吃下攻擊黑塊碎開，被擋住的光整片湧出來——最戲劇性的一刻
Visual language
角色永遠是純黑。黑形對亮底是投影機上能達到的最高對比，而且它不依賴任何顏色——這是三個方向裡對 C4 最徹底的解法。
第二層編碼（Q02）
身分不在人身上，在幕上。左半幕暖橘、右半幕冷青，亮度差 3.4 倍。人走到哪，身分就跟著背後那道光。
對手消失（Q03）
剪影併入黑塊變成同一團黑。你看得到那團黑，所以知道他在裡面——躲藏＝合體，不是消失。
數值牌（Q04）
不在頭頂，燒在幕布上緣。因為身分已經由幕承擔了，數值跟著幕走——永遠不會被牆或角色擋住，而且可以放到超大。
Motion
光會呼吸（幕的亮度 ±4%，週期 6s）、法陣把幕烤亮。不動的是：剪影的輪廓與地面線——形狀永遠銳利，只有光在變。
Best case
當「台上那 90 秒」的權重遠高於「judge 自己玩」時。這是三個裡遠距離讀得最快、也最像一場表演的。
色票Hex相對亮度對剪影黑閘門
Anti-generic：NO — 它長成這個遊戲的樣子
  1. 身分由背景光承擔，因為玩家會在自己的半場來回走位——走位本身就是這個遊戲
  2. 躲藏＝剪影併入黑塊，把「看不到對手」變成一個形狀事件，不是一個 UI 狀態
  3. 皮影戲本來就是用手在光前面做出東西——跟玩家在鏡頭前用筆畫符文是同一件事
Risk

冷側只有 3.3:1，暖側有 9.1:1——兩邊不對等。青光那一半的玩家會比較難讀，這是必須靠調色收斂的真缺陷。 而且純黑剪影看不出角色在畫什麼符文，所有施法資訊都得靠法陣與拖尾承擔。

Stage 4 要決定什麼

挑一個，並且說出放棄了什麼。以下是我認為真正的取捨：

  1. 選星圖＝賭會場能關燈。拿到最高的美術上限與團隊熟悉度，賭輸就整場看不見。
  2. 選石版＝放棄發光與「深夜魔法」氛圍，換到投影機上幾乎不可能失敗的對比。最安全，也最需要膽量。
  3. 選皮影＝賭「台上 90 秒」比「judge 自己玩」重要。遠距離最好讀，但玩家看不見自己在畫什麼。
  4. 先做一件事再決定：把這一頁在會場的投影機上打開，四個模擬全開，站到十公尺外。三個方向會自己淘汰兩個。
