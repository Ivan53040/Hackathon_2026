## 1. 為什麼現在像講台

不是「不夠精緻」，是四件具體的事：

1. **兩塊一模一樣的平台面對面** —— 對稱、等高、彼此孤立。這就是講台的定義
2. **中間的地面沒有被設計** —— 一張純色 plane 加一個 `GridHelper`，讀起來像 debug 格線
3. **沒有邊界** —— 四周是開放的夜空，沒有「我在某個地方裡面」的感覺
4. **中景是空的** —— 近景平台、遠景尖塔，`z ∈ [−3, −7]` 什麼都沒有，眼睛沒有落點

**核心問題是第 1 點**：兩個人站在「兩件家具」上，而不是站在「同一個空間」裡。
把他們放進一個共用的、被設計過的場地，講台感就會消失。

---

## 2. 美術方向：高塔頂端的儀式決鬥場

一句話：**這不是舞台，這是一座塔的頂端，一個刻著符文的圓形決鬥場，四周是斷掉的柱廊，
再外面就是夜空與遠處的城市。**

具體怎麼讀出來：

- **地面變成一個大的嵌刻符文圓盤**，圓心在兩人中間（`z ≈ −4`）。
  同心圓 + 符文帶。這一項最有效 —— 它一次解決第 2 點和第 1 點：
  兩人不再是各站各的台，而是站在同一個圓的兩端
- **外圈一圈斷掉的石柱 / 拱門**，圍出邊界但**要有缺口**，不能像個盒子
- **圓盤外緣之後是斷崖** —— 地面在半徑之外收掉，讓人知道這裡很高。
  外面的黑暗交給既有的霧處理
- **兩塊平台不要再是孤立的方塊** —— 用台階、基座把它們接進圓盤，變成圓盤的一部分

如果你有更好的方向，可以提，但**先把「兩人共用一個被設計過的場地」這件事做到**。

## 3. 場地尺寸（照抄，不要自己猜）

```
相機（我）      x = 0,  y = 1.6,  z = 0        FOV 55°，視線水平
我的平台        z = 0.6
對手            z = −7.5                       ← 🔴 這條視線不能被擋
對手的平台      z = −8.5   (GAP = 8.5)
橫向範圍        x ∈ [−3, 3]                    (LANE_WIDTH = 6)
地板            y = −0.65
平台            y = −0.3，厚 0.6，深 3.2
圓盤圓心建議     z ≈ −4
```

**霧已經存在**：`Fog(--void, 7.65, 28.9)`。
放在 28.9 以外的東西會被吃光 —— 要嘛放進範圍內，要嘛材質設 `fog: false`
（既有的月亮、星星、遠處尖塔都是 `fog: false`）。

**既有的東西不用重做**：天空球漸層、260 顆星星、月亮 + 光暈、5 座遠處尖塔剪影、
地板 plane、兩塊平台 + 受光邊、三盞燈、霧。

## 5. 硬規則（會被檢查）

- 🔴 **中間 1/3 畫面必須完全淨空。** 對手在 `z = −7.5`，玩家要隨時看得到他全身
  跟頭頂的血魔量。柱子放在 `|x| > 4`，拱門的橫樑要高過 `y = 3.5`
- **顏色一律從 `src/ui/tokens.css` 讀**，不准寫死 hex：
  ```ts
  new THREE.Color(getComputedStyle(document.documentElement).getPropertyValue('--struct').trim())
  ```
  可用：`--void --struct --struct-lit --me --them --spell-core --magic --ash`
  ⚠️ **不要用 `--them` / `--them-hot` 做裝飾** —— 那是敵方識別色，
  場景搶了會害玩家把柱子看成對手
  ⚠️ **也不要用 `--me` 大面積鋪** —— 那是我方色，HUD 在用
  場景主色請用 `--struct` / `--struct-lit`
- **不准加新的光源。** 現在 3 盞，再加會掉 fps。要發亮用 `MeshBasicMaterial`
- **不准在 `updateScenery` 裡配置物件**（每幀熱路徑）。要動的在 `buildScenery` 就開好
- **重複的東西共用 geometry 與 material**，或直接用 `InstancedMesh`。
  20 根柱子開 20 個 `BoxGeometry` 是不行的
- **不准引入新的 npm 套件**
- **不准改 `src/core/config.ts` 的數值**
- **不准 `git add` / `commit` / `push`**（見 `rules.md`）
