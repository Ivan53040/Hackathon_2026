## 🔴 三處要改

### 1. 沒有多層塔，只有一層

Demo 圖畫了三層塔、樓梯、六個法師。**v6 已經砍掉樓層。**
場地是**兩塊面對面的平台，各自單層**，角色只能左右橫移。

→ **背景板請畫成單層對峙的場景**，不要有可以爬的樓梯。

### 2. 沒有 3v3，只有 1v1

Demo 圖有六個法師。**36 小時內只做 1v1。**

→ 角色素材**只要一套**（對手）。玩家自己是第一人稱，看不到自己。
→ 這件事讓你的工作量直接砍一半。

### 3. 沒有 1/2/3/4 技能列，只有兩個符文

Demo 圖下方有四格快捷技能。**v6 只有兩招，而且不用按鍵選 —— 用畫的。**

| 符文 | 招式 |
|---|---|
| **△** | 攻擊 |
| **□** | 建造遮蔽物 |

→ HUD 下方請改成**兩個符文小抄**（畫給玩家看形狀），不是技能格。

## 🔴 最重要的一條：攻擊特效要兩個色版

概念圖的攻擊是水晶藍。但**兩邊玩家都會發射攻擊** ——
如果雙方都是藍的，玩家在最關鍵的一刻（有東西朝我飛過來）分不出那是誰的。

**做法：核心保持水晶白藍，外圈光暈做兩版。**

```
我方攻擊   核心 #E6F2FF   外圈光暈 #D4AF37（暖金）
敵方攻擊   核心 #E6F2FF   外圈光暈 #3CC6FF（水晶藍）
```

**外圈厚度至少是核心半徑的 1.5 倍** —— 投影機上 bloom 會把細光圈吃掉。

## 🎨 定案色票（已寫進 `src/ui/tokens.css`）

概念圖的色票**有一個地方直接用會失效**，我調了一階：

| 用途 | 色值 | 說明 |
|---|---|---|
| 底 | `#0E182F` | 概念圖 DEEP BLUE，直接採用 |
| 建築 | `#5C6EAE` / `#8FA0D8` | 對底 3.61:1，投影機上塔才不會消失 |
| **我方** | `#D4AF37` | 概念圖 GOLD ACCENT，直接採用 |
| **敵方** | `#1E7FB8` | ⚠️ **不是概念圖的 `#3CC6FF`** |
| 敵方亮部 | `#3CC6FF` | 概念圖 CRYSTAL BLUE，保留當核心與光暈 |
| 法術核心 | `#E6F2FF` | 概念圖 LIGHT BLUE |
| 吸附爆光 | `#5A3DFF` | 概念圖 MAGIC PURPLE |

> **為什麼敵方識別色要壓深**：`#3CC6FF` 跟金色 `#D4AF37` 的**相對亮度只差 1.08 倍**。
> 投影機洗掉飽和度、或轉成灰階之後，**兩邊會變成同一個顏色**，觀眾分不出誰打誰。
> 壓深到 `#1E7FB8` 之後亮度差 2.38 倍，灰階下仍然分得開，而且視覺上還是同一個水晶藍家族。
>
> 這一條是硬約束，見 [`../.design/00-brief.md`](../.design/00-brief.md) C3/C4。
